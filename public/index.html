Agent Executor

Early Preview

A distributed agent runtime designed for reliability, customizability, and efficiency.

GitHub

Resumable and autonomous

Automatic recovery and resumption from failures, even across complex distributed deployments.

Customizable

The runtime is fully customizable with tools, skills, and purpose-built agents for any domain or workflow.

Kubernetes-native

Designed to run on Agent Substrate with first-class Kubernetes support.

Model and harness agnostic

Bring your own LLM and planning logic. AX handles execution, durability, and coordination underneath.

Open protocols

Native support for MCP, A2A, and other agentic protocols. AX agents can interoperate with tools and agents across the ecosystem.

Auditing and observability

Full audit trail, observability hooks, and trajectory collection for every execution.
