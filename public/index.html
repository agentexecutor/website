AX

A distributed agent runtime designed for reliability.

GitHub

Reliable by default

Automatic recovery and resumption from failures, even across complex distributed deployments.

Durable event log

Single-writer consistency guarantees and built-in auditing for every agentic operation.

Model agnostic

Works with any model or framework. Ships with a built-in Gemini planner.

Kubernetes-native

Designed to run on Agent Substrate with first-class Kubernetes support.

Open protocols

Speaks A2A and Google ADK protocols alongside the native AX gRPC interface.

Policy & audit controls

Built-in controls for governing what agents are allowed to do and a full audit trail.

AX is an open source project. github.com/google/ax
